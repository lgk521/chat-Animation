# 码道+AI Shell打造任务看板部署

## 案例简介

本案例基于华为云码道（CodeArts）代码智能体和华为云AI Shell快速生成与部署Vue3 + Vite + localStorage搭建纯前端任务管理看板，支持新建任务卡片、自定义标题描述与分类、通过拖拽自由切换任务状态、搭配分类标签快速筛选，全部操作自动存储至localStorage，页面刷新数据不会丢失，同时部署至华为云服务器进行上线。

## 技术选型

- **华为云码道（CodeArts）代码智能体**：基于智能生成、智能问答两大核心能力构建全方位智能开发体系
- **华为云AI Shell**：智能AI命令行工具，以自然语言驱动终端操作，一站式完成华为云资源查询、操作、运维工作
- **GitCode MCP Server**：模型上下文协议服务实现，将AI助手深度集成到代码管理流程中

## 适用对象

- 个人开发者
- 高校学生
- 企业开发者

## 案例时长

60分钟

## 学习目标

通过本案例学习，您将掌握：

1. 使用华为云码道代码智能体进行应用开发
2. 配置GitCode MCP Server进行代码管理
3. 使用AI Shell进行应用部署
4. 纯前端应用的架构设计与实现
